Thin pill progress bar for a packing session; pine while packing, ember when complete.

```jsx
<ProgressBar value={3} max={7} />
<ProgressBar value={7} max={7} />
<Card tone="brand"><ProgressBar inverse value={7} max={7} /></Card>
```

Use one per session card and at the top of the session screen. 8px tall, never thicker.
